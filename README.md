# PNE — POSM theo chương trình

Trang tra cứu POSM (flyer / brochure / standee) của Phương Nam Education, gom theo chương trình.

Xem trang: https://hueptt-bit.github.io/pne-posm/

## Nội dung

- 8 chương trình: Đức (6, gồm hai đối tác Azurit Hansa và Buhmann), Áo (1), Canada (1)
- Mỗi chương trình cần 1 file in (flyer hoặc brochure) và 1 standee
- Ảnh preview lấy trực tiếp từ Google Drive
- Tìm kiếm không dấu, lọc theo thị trường / thiếu standee / file trên 3 năm, sắp xếp theo độ cũ
- Nút sao chép link từng file

## Lưu ý

Trang là một file index.html tĩnh, không cần build.
Ảnh preview chỉ hiện khi file trên Drive đang ở chế độ chia sẻ "Bất kỳ ai có đường liên kết".
